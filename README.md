# Aahan Srivastava — Portfolio

## Run locally

Requires Node 14 (see `.nvmrc`).

```sh
yarn
npm start
```

Then open http://localhost:8000.

## Where to edit things

| What | Where |
| --- | --- |
| Email, social links, colors | `src/config.js` |
| Site title, description, URL | `gatsby-config.js` |
| Hero text | `src/components/sections/hero.js` |
| About text and skills | `src/components/sections/about.js` |
| Your photo | `src/images/me.jpg` |
| Jobs / experience | `content/jobs/*/index.md` |
| Featured projects | `content/featured/*/index.md` (+ `cover.png` screenshot) |
| Other projects and archive | `content/projects/*.md` |
| Resume PDF | `static/resume.pdf` |
